========================================
KOREAN LANGUAGE JOURNEY
DAY 04 — DEMONSTRATIVES
========================================

GOAL:
Practise 이것, 그것, 저것 and their
short forms 이거, 그거, 저거.


----------------------------------------
1. DEMONSTRATIVE WORDS
----------------------------------------

이것 = igeot = this thing
그것 = geugeot = that thing
저것 = jeogeot = that thing over there

이거 = igeo = this thing (casual)
그거 = geugeo = that thing (casual)
저거 = jeogeo = that thing over there (casual)


----------------------------------------
2. BASIC SENTENCES
----------------------------------------

이것은 책이에요.
This is a book.

그것은 물이에요.
That is water.

저것은 가방이에요.
That over there is a bag.

이거는 뭐예요?
What is this?

저거는 의자예요.
That over there is a chair.


----------------------------------------
3. VOCABULARY
----------------------------------------

책 = chaek = book
물 = mul = water
가방 = gabang = bag
의자 = uija = chair
학교 = hakgyo = school
연필 = yeonpil = pencil
핸드폰 = haendeupon = mobile phone
시계 = sigye = clock / watch
문 = mun = door
책상 = chaeksang = desk


----------------------------------------
4. SENTENCE PATTERNS
----------------------------------------

이것은 + noun + 이에요/예요.

Example:
이것은 책이에요.
This is a book.

이거는 뭐예요?
What is this?

이것은 연필이에요.
This is a pencil.


----------------------------------------
5. IMPORTANT REMINDER
----------------------------------------

이 = near the speaker
그 = near the listener or already mentioned
저 = far from both people

것 = thing

이에요/예요 = is/am/are (polite)
