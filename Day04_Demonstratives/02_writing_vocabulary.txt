PART 2 — VOCABULARY WRITING
----------------------------------------

Write each Korean word 3 times.

1. 책 = book
2. 물 = water
3. 가방 = bag
4. 의자 = chair
5. 학교 = school
6. 연필 = pencil
7. 핸드폰 = mobile phone
8. 시계 = clock / watch
9. 문 = door
10. 책상 = desk


----------------------------------------
PART 3 — COMPLETE THE SENTENCE
----------------------------------------

Use the correct demonstrative.

1. ______ 책이에요.
   This is a book.

2. ______ 물이에요.
   That is water.

3. ______ 가방이에요.
   That over there is a bag.

4. ______ 뭐예요?
   What is this?

5. ______ 의자예요.
   That over there is a chair.


----------------------------------------
PART 4 — BUILD SENTENCES
----------------------------------------

Translate into Korean.

1. This is a book.

2. That is water.

3. That over there is a bag.

4. What is this?

5. This is a pencil.


----------------------------------------
PART 5 — WORD ORDER PRACTICE
----------------------------------------

Arrange the words correctly.

1. 책이에요 / 이것은

3. 저것은 / 가방이에요

4. 뭐예요 / 이거는

5. 연필이에요 / 이것은
